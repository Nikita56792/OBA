# Объёмный звук 5.1 / 6.1 / 7.1 в Sony WH-1000XM6 на Mac

Задача: чтобы при просмотре фильма (например, «Начало» 2010 с дорожкой AC3 6.1) на
MacBook Pro 2024 (Apple Silicon, macOS 27) каждый канал звучал в наушниках со своего
места, как в настоящей системе: фронт спереди, боковые сбоку, тылы сзади. Наушники
подключаются по Bluetooth или по кабелю.

## Почему сейчас не получается

По Bluetooth и по кабелю в наушники приходят только **2 канала**. Чтобы 6–8 каналов
«встали по местам», их нужно заранее, ещё на Mac, свернуть в бинауральное стерео.
Каждый канал пропускается через импульсные отклики «колонка → левое ухо» и
«колонка → правое ухо» (HRTF, а с отражениями комнаты — BRIR). Так работают Dolby
Atmos for Headphones, DTS Headphone:X и HeSuVi на Windows.

| Что пробовали | Что происходит на самом деле |
|---|---|
| **Infuse** на Mac | Виртуализатор для наушников есть только через Apple Spatial Audio, а он работает лишь с AirPods и Beats. С другими наушниками Infuse делает обычный стереодаунмикс: тылы подмешиваются в левый и правый каналы и позиции не получают. В настройках есть только «LFE в даунмиксе» и громкость даунмикса, отдельной обработки для наушников нет. |
| **VLC**, режим «Наушники» | VLC 3.x включает бинаурализатор `spatialaudio` с безэховой HRTF от 3D Sound Labs (`dodeca_and_7channel_3DSL_HRTF.sofa`). Без отражений комнаты звук остаётся «внутри головы» и кажется тусклее, чем в режиме «Оригинал». Кроме того, в коде VLC позиции задаются только для L/R, боковой пары, тыловой пары, центра и LFE ([`spatialaudio.cpp`](https://github.com/videolan/vlc/blob/3.0.x/modules/audio_filter/channel_mixer/spatialaudio.cpp), `OpenBinauralizer`). У настоящей 7-канальной дорожки 6.1 задний центр (Rear Center) своей позиции не получает, и все каналы после него сдвигаются: задний центр оказывается на месте фронтального центра. |
| **Sony, режим Cinema** (360 Upmix for Cinema) | Делает «объём» из уже сведённого стерео. Про исходные дискретные каналы ничего не знает. Работает только по Bluetooth. |

## Решение: свёртка каждого канала с BRIR

Скрипт [`binaural.sh`](binaural.sh) делает на Mac то же, что HeSuVi на Windows:

- берёт пресеты HeSuVi: Dolby Atmos for Headphones, DTS Headphone:X, Sennheiser GSX,
  Dolby Headphone, Windows Sonic, Out Of Your Head, Waves Nx и ещё около 50, плюс около 250
  HRTF манекенов и людей из баз ARI, CIPIC, IRCAM, MIT, Club Fritz;
- переставляет их каналы в формат фильтра `headphone` из FFmpeg и выравнивает громкость,
  чтобы пресеты можно было честно сравнивать на слух;
- подключает фильтр в **IINA** и **mpv** (обработка в реальном времени) или встраивает
  готовую бинауральную дорожку в MKV для **Infuse** и любого другого плеера.

Раскладка проверена на тестовых сигналах. Каждый канал попадает в свою пару откликов,
левое ухо для левых колонок получает звук раньше и громче. Задний центр 6.1 делится
поровну (−3 дБ) между двумя тыловыми виртуальными колонками, то есть звучит строго сзади.

### 1. Установка (один раз)

```bash
# Homebrew: https://brew.sh
brew install ffmpeg
brew install --cask iina      # или: brew install mpv

# положите binaural.sh в любую папку и выполните:
bash binaural.sh setup        # скачает HeSuVi (~27 МБ) и подготовит ~300 пресетов в ~/Binaural
```

Для распаковки хватает встроенного `tar`, 7-Zip не нужен.

### 2. Подбор пресета под свои уши

```bash
bash binaural.sh test                          # atmos, dtshx, gsx, dh++, ooyh1 по очереди
bash binaural.sh test sonic waves cmss_ent     # любые другие, список: bash binaural.sh list
```

Голос по очереди обходит круг: «Левый фронт → Центр → Правый фронт → Правый бок →
Правый тыл → Тыл, центр → Левый тыл → Левый бок». Файлы остаются в `~/Binaural`
(`test-<пресет>.wav`, а также `test-plain-downmix.wav` — обычный даунмикс для
сравнения), их можно переслушивать. Лучший пресет тот, с которым тылы у **вас**
слышны сзади, а не спереди или внутри головы. Это зависит от формы ушей, поэтому
универсального ответа нет.

### 3а. IINA — обработка в реальном времени

```bash
bash binaural.sh filter -p atmos
```

Скрипт выведет готовую строку. Варианты подключения в IINA:

- **Аудио → Аудиофильтры → Сохранённые фильтры → «+»**: вставить строку `lavfi="…"`
  целиком и назначить сочетание клавиш. Тогда обработку можно включать и выключать
  на лету, чтобы сравнивать.
- **Настройки → Дополнительно → Дополнительные параметры mpv**: параметр `af`,
  значение `@binaural:lavfi="…"`. Так фильтр включён всегда.

Если IINA сообщит, что не знает фильтр (у неё своя сборка FFmpeg), используйте mpv.

### 3б. mpv

```bash
bash binaural.sh mpv -p atmos      # пропишет фильтр в ~/.config/mpv, Ctrl+b — вкл/выкл
```

### 3в. Infuse (и любой другой плеер): готовая дорожка

```bash
bash binaural.sh tracks "Inception.2010.mkv"                     # номера аудиодорожек
bash binaural.sh render -p atmos -a 0 "Inception.2010.mkv"       # -a — нужная дорожка
```

Рядом появится `Inception.2010.binaural-atmos.mkv`: всё исходное (видео, дорожки,
субтитры) скопировано без изменений, плюс дорожка **«Binaural (atmos)»** в FLAC 24 бит
без потерь. Её и выбирайте в Infuse. Сжатие AAC для Bluetooth macOS сделает один раз,
при передаче. Если важен размер, есть `-c aac`: около 350 МБ вместо ~1,5 ГБ на 2,5 часа.

### Параметры

| Опция | Что делает |
|---|---|
| `-p ПРЕСЕТ` | набор откликов, по умолчанию `atmos` |
| `-g ДБ` | усиление после свёртки, по умолчанию 22 (громкость ≈ как у обычного даунмикса); на пиках срабатывает мягкий лимитер |
| `-l ДБ` | уровень сабвуферного канала LFE относительно остальных, по умолчанию 0 |
| `-e ПРОФИЛЬ` | коррекция АЧХ наушников по AutoEq (цель Harman): `xm6-bt-kuulokenurkka`, `xm6-bt-superreview`, `xm6-cable-superreview` (для кабеля) или путь к любому `*ParametricEQ.txt`; по умолчанию `none` |
| `-s side\|back\|wide` | только `render`, только для дорожек 5.x: тылы на 90°, на 135–150° или между ними (≈110°, как в ITU-R BS.775) |

## Про «AC3 6.1»

Формат AC3 (Dolby Digital) физически вмещает максимум 5.1. «AC3 6.1» — это Dolby Digital EX:
задний центр **матрично** подмешан в оба тыловых канала, и декодер (FFmpeg, VLC, Infuse)
выдаёт 5.1. Проверить можно командой `bash binaural.sh tracks файл`:

- `5.1(side)` — это EX или обычное 5.1. Задний центр сидит в тылах как одинаковый сигнал
  в обоих. С `-s back` или `-s wide` он окажется за спиной, а не по бокам.
- `6.1` — задний центр отдельным каналом (E-AC3, DTS-ES и т. п.). Скрипт отдаст его поровну
  в обе тыловые виртуальные колонки.

## Настройка наушников и Mac

- **Sony Sound Connect → Звук → Режим прослушивания: «Стандартный».** Режим Cinema
  (360 Upmix) нужно выключить, иначе звук пройдёт пространственную обработку дважды.
- **Эквалайзер Sony.** Пресеты откликов рассчитаны на наушники с ровной АЧХ, а у XM6
  заметно поднят бас. Можно выключить эквалайзер Sony, использовать `-e` или сравнить
  на слух оба варианта.
- **Bluetooth.** Mac передаёт звук в AAC (~256 кбит/с). LDAC macOS не поддерживает.
  В «Системные настройки → Звук → Вход» выберите микрофон MacBook. Если входом станет
  микрофон наушников, macOS переключит их в режим гарнитуры, и звук станет плохим.
- **Кабель AUX (3,5 мм).** Нет сжатия AAC и задержки Bluetooth. Режим Cinema по кабелю
  не работает, поэтому мешать не будет. Включённые (активный режим) и выключенные
  (пассивный) наушники звучат по-разному, а для кабеля есть свой профиль
  `-e xm6-cable-superreview`.
  В «Настройке Audio-MIDI» для «Внешних наушников» имеет смысл выставить 48 000 Гц,
  как у звука в фильмах.
- **Рассинхрон по Bluetooth.** mpv и IINA учитывают задержку устройства. Если губы всё же
  «отстают», звук можно сдвинуть в меню плеера.

## Честно об ограничениях

- У XM6 на Mac нет отслеживания положения головы: сцена поворачивается вместе с головой.
  Без этого у части людей тылы иногда «перескакивают» вперёд. Сильнее всего помогает
  подобрать подходящий пресет. Пресеты с комнатой (atmos, dtshx, gsx, dh++, ooyh1 и
  варианты с `+`) обычно лучше выносят звук из головы, чем безэховые (с `-` на конце и базы
  ari/cipic/irc/mit/cf).
- Пресеты HeSuVi — это записи откликов коммерческих виртуализаторов и научные базы HRTF,
  персональной HRTF среди них нет. Персонализация Sony (фото ушей в приложении) применяется
  только в собственной обработке Sony (360 Reality Audio / 360 Upmix), для этой обработки
  она недоступна.
- Для обычных стереодорожек фильтр создаёт две виртуальные колонки перед слушателем.
  Если это не нужно, выключите фильтр (Ctrl+b в mpv, сохранённый фильтр в IINA).

## Альтернативы (коротко)

- **AirPods Pro / Max + Infuse** — родное Apple Spatial Audio с отслеживанием головы.
  На Mac работает только с наушниками Apple и Beats.
- **Трюк с агрегатным устройством** ([описание](https://gist.github.com/ParkWardRR/a8c0e765b16c763efb6316c83efa0fb2)):
  заставляет macOS включить Spatial Audio через встроенные динамики как ведущее устройство
  и перенаправить результат на другой выход. Трюк хрупкий, работает только в IINA/mpv с
  AVFoundation, с Bluetooth автор его не проверял. К тому же это рендер для динамиков
  ноутбука, а не для наушников.
- **Плагины-виртуализаторы** (SPARTA Binauraliser — бесплатный, dearVR MONITOR,
  APL Virtuoso, Waves Nx) через виртуальное устройство BlackHole и хост плагинов.
  Работает с любым плеером, но настраивать заметно сложнее.
